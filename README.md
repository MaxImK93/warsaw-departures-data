# Warsaw Departures Data

Compact Warsaw SKM schedule used by the Warsaw Departures iOS application.

The schedule is rebuilt automatically every day from the public
[Warsaw GTFS feed](https://mkuran.pl/gtfs/) and retains the previous valid file
if downloading, conversion, or validation fails.
